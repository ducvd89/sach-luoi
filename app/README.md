# sach_noi

Mã nguồn ứng dụng **Sách lười** (Flutter, Windows + Android).

Tên gói Dart vẫn là `sach_noi` và applicationId Android vẫn là
`com.sachnoi.sach_noi`: đổi hai thứ đó là máy coi như một ứng dụng khác, người
dùng mất sạch thư viện sách và phải tải lại mô hình giọng nói.

Hướng dẫn cài đặt, cách dùng và cấu trúc dự án nằm ở [README ngoài gốc](../README.md).
